# How to regenerate the web icons

The web icons are PNG files generated from the SVG logos in `assets/`. Regenerate them after a
change to the logo.

## Prerequisites

- `rsvg-convert` (librsvg) renders the SVG files.
- `magick` (ImageMagick 7) removes the alpha channel.

On macOS: `brew install librsvg imagemagick`. Neither is a dependency of the project.

## Sources and outputs

| Source                     | Output                               | Size | Use                                   |
| -------------------------- | ------------------------------------ | ---- | ------------------------------------- |
| `assets/icon-square.svg`   | `public/apple-touch-icon.png`        | 180  | iOS home screen                       |
| `assets/icon-square.svg`   | `public/icons/icon-192.png`          | 192  | Manifest, purpose `any`               |
| `assets/icon-square.svg`   | `public/icons/icon-512.png`          | 512  | Manifest, purpose `any`, link preview |
| `assets/icon-maskable.svg` | `public/icons/icon-maskable-512.png` | 512  | Manifest, purpose `maskable`          |
| `assets/icon.svg`          | `assets/images/favicon.png`          | 512  | Browser tab (`web.favicon`)           |

- `icon-square.svg` is the logo on a full-bleed cream square: a home screen rounds the corners
  itself.
- `icon-maskable.svg` scales the mark by 0.8 so it stays inside the maskable safe zone, a centred
  circle with a radius of 40% of the icon size. Its comment gives the computation.
- `icon.svg` is the round logo. Its transparent corners are fine at tab size. At export, Expo turns
  `favicon.png` into `dist/favicon.ico` (16, 32 and 48 px) and adds the `<link rel="icon">` itself.

## Generate the PNG files

From the repository root:

```bash
for size in 192 512; do
  rsvg-convert -w "$size" -h "$size" assets/icon-square.svg \
    | magick png:- -background '#F7F4EF' -alpha remove -alpha off -strip "PNG24:public/icons/icon-$size.png"
done
rsvg-convert -w 180 -h 180 assets/icon-square.svg \
  | magick png:- -background '#F7F4EF' -alpha remove -alpha off -strip PNG24:public/apple-touch-icon.png
rsvg-convert -w 512 -h 512 assets/icon-maskable.svg \
  | magick png:- -background '#F7F4EF' -alpha remove -alpha off -strip PNG24:public/icons/icon-maskable-512.png
rsvg-convert -w 512 -h 512 assets/icon.svg -o assets/images/favicon.png
```

- `rsvg-convert` always writes an alpha channel. `magick` flattens the image on cream and writes it
  as RGB, because iOS paints transparent pixels of a home screen icon black.
- `-strip` drops the timestamps ImageMagick writes, so the same SVG gives the same PNG.

## Check the result

```bash
magick identify -format '%f %wx%h %[channels]\n' public/apple-touch-icon.png public/icons/*.png
```

Each file must show its size and `srgb`, not `srgba`. Keep `icon-512.png` at 512 × 512:
`src/app/+html.tsx` declares that size for the link preview image.

The native app icons (`assets/images/icon.png` and its variants) are not generated by these
commands.
