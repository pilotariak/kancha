# AGENTS.md — Kancha

**Kancha** is the Pilotariak mobile application for Basque pelota competition management.
Built with React Native, Expo (SDK 54), and TypeScript. Targets iOS, Android, and web.

## Architecture

```
kancha/
├── src/              # Application source code
│   ├── app/          # Expo Router file-based routes
│   ├── components/   # Shared UI components
│   └── ...
├── assets/           # Images, fonts, icons
├── ios/              # Native iOS project (generated by Expo prebuild)
├── android/          # Native Android project (generated by Expo prebuild)
└── public/           # Static assets for web
```

## Key Dependencies

| Library                               | Purpose                      |
| ------------------------------------- | ---------------------------- |
| `expo-router`                         | File-based navigation (v6)   |
| `@tanstack/react-query`               | Server state / data fetching |
| `zustand`                             | Client-side state management |
| `react-i18next` + `expo-localization` | i18n (en, fr)                |
| `lucide-react-native`                 | Icon set                     |

Data comes from **Frontis** (GraphQL gateway at `https://frontis-gateway.pilotariak.com/graphql`).

## Dev Setup

Requirements: [Bun](https://bun.sh) ≥ 1.1, [Expo CLI](https://docs.expo.dev/get-started/installation/)

```bash
bun install          # install dependencies
```

Environment files:

- `.env.development` — used by Expo Go and local dev
- `.env.production` — used by EAS production builds
- `.env` — local overrides (git-ignored)

## Running the App

```bash
# Expo Go (fastest, no native build needed)
bunx expo start
make run-expo

# iOS simulator
bunx expo start --ios
make run-ios

# Android emulator
bunx expo start --android
make run-android

# Web browser
bunx expo start --web
make run-web
```

## Native Builds (EAS)

```bash
make eas-login                          # authenticate with Expo
make eas-build-ios PROFILE=development  # build iOS (development|production)
make eas-build-android PROFILE=development
make eas-build-all PROFILE=production
```

EAS config: `eas.json`. Build profiles: `development`, `production`.

## Web Deployment (Cloudflare Pages)

```bash
bunx expo export --platform web         # export to dist/
make cf-deploy-web                      # deploy to Cloudflare Pages (project: kancha-website)
```

## Key Conventions

- **TypeScript** throughout; strict mode enabled
- **Expo Router** file-based routing — add screens by creating files in `src/app/`
- **i18n**: translation keys in `src/locales/`; always use `useTranslation()` for user-facing strings
- **Data fetching**: use TanStack Query hooks — don't call GraphQL directly from components
- Formatting: `dprint` (config in `dprint.json`)
- Design system documented in `DESIGN.md`

## Useful Commands

```bash
bunx expo prebuild         # regenerate ios/ and android/ from app.config.js
make build-ios             # prebuild + run on iOS
make build-android         # prebuild + run on Android
make eas-configure         # link project to EAS (first-time setup)
```
